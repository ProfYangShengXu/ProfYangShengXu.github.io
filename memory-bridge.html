memory-bridge

Memory Layer

给智能体使用的长期记忆层。

GitHubSOURCE 接入指南GUIDE

是什么

一个面向智能体的记忆层。把会话中值得保留的内容沉淀成长期记忆， 并在新的上下文中按相关性取回。

做什么

区分不同类别的记忆并分别设定生命周期；按当前上下文检索相关条目； 附带评测集，可以对比不同检索策略的效果。

为什么这么做

智能体的上下文窗口是一次性的，但有些信息不应该随会话结束而消失 —— 用户偏好、项目里已经做过的决定、踩过的坑。

把这些内容全部塞回上下文并不现实，所以需要一层能判断"当前该取回什么"的机制。 带评测集是为了让检索策略的改动有可比性，而不是凭感觉调。
